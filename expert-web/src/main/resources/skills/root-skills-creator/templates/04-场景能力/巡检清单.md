# {项目名}巡检清单

## 巡检概述

**适用范围**：{项目名} {版本号}

**巡检目的**：
- 验证系统各环节健康状态
- 提前发现潜在风险
- 确保黄金指标处于正常范围
- 验证数据实体完整性

**巡检依据**：
- 来源于 `02-领域认知/整体架构.md` 定义的黄金指标
- **须与训练时加载的指标体系元数据（默认从 `/app/upload/data` 读取）中标记为黄金的条目一致**：巡检项中的指标名、标识符以元数据为准，与整体架构交叉校验无遗漏
- 来源于 `03-实体模型/` 定义的实体生命周期检查点
- 来源于各环节的故障模式定义

**黄金指标巡检（强制）**：
- 对每个环节，凡在元数据或 `整体架构.md` 中标记为**黄金**的指标，本清单中必须有对应检查项（含预期值/阈值/检查方式占位，由生成时按元数据与文档补全）。
- 禁止只巡检部分黄金指标；若元数据与架构表不一致，以元数据为准更新检查项并需在巡检概述中说明一次「已对齐元数据」。

## 月巡检

### 检查项1：全环节健康汇总

**检查范围**：所有环节的所有黄金指标（与 `/app/upload/data` 元数据黄金集合一致）

**检查步骤**：
1. 读取 `02-领域认知/整体架构.md` 获取全部环节和黄金指标，并与元数据黄金指标列表逐项对账
2. 批量查询所有黄金指标（最近 1 天）
3. 统计异常指标数量和分布；若有黄金指标未出现在清单检查项中，视为本次生成不合格，须补全后再交付

### 检查项2：故障模式匹配检查

**检查内容**：
- 是否存在已定义故障模式的早期征兆

**检查步骤**：
1. 遍历各环节的 `02-领域认知/{环节}/整体逻辑.md` 中的故障模式
2. 检查对应指标是否出现早期异常特征
3. 提前预警潜在风险

## 巡检执行流程

### 自动巡检（推荐）

```
1. 选择版本
2. 加载本清单
3. 按检查频率（日/周/月）筛选检查项
4. 对每个检查项：
   - 查询指标/实体数据
   - 对比预期值
   - 标记异常
5. 生成巡检报告
6. 对异常项：
   - 关联故障模式（参考 02-领域认知/{环节}/整体逻辑.md）
   - 定位数据实体（参考 03-实体模型/{实体}.md）
   - 必要时转入排障流程（调用 04-场景能力/故障排查思路.md）
```

### 手动巡检

```
1. 选择要检查的环节/实体
2. 读取 02-领域认知/{环节}/整体逻辑.md 或 03-实体模型/{实体}.md
3. 查询该环节的黄金指标或实体数据
4. 对照本清单的预期值
5. 记录结果
```

## 实体数据检查示例

### 示例1：订单实体日检

**检查项**：订单创建是否正常

**执行步骤**：
1. 读取 `03-实体模型/订单.md` 了解订单字段
2. 统计最近 1 小时订单创建数量
3. 对比昨日同期数据
4. 检查订单状态分布是否正常

**判定标准**：
- 创建数量波动 < 30% → 正常
- 状态分布符合预期比例 → 正常

**异常处理**：
- 若异常 → 读取 `02-领域认知/订单服务/订单创建.md` 排查
- 必要时 → 转入 04-场景能力/故障排查思路.md
