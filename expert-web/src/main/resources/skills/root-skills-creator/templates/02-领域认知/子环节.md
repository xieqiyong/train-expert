    ├─ 指标采集: apm_trace_query_latency Timer 结束
    └─ 输出: Result<TraceTree>
    ↓

    │  字段: traceId, rootSpan, totalSpans, duration, hasError
    │  去向: 返回前端 / 被 AgentBrain 消费
