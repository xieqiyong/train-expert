# {项目名}实体模型总览

## 实体模型概述

**设计目的**：
- 按**数据实体**横向组织，建立跨环节的数据视图
- 明确每个实体的字段来源于哪些领域认知环节
- 为问数、巡检提供统一的数据入口

**与领域认知的关系**：
- **02-领域认知**：按环节纵向组织（流程视角）— 描述"数据如何流动"
- **03-实体模型**：按实体横向组织（数据视角）— 描述"数据如何组成"
- 两者通过【字段来源】建立映射，互为补充

**使用场景**：
- **智能问数**：基于实体定义理解用户查询目标
- **故障排查**：通过实体定位异常数据的位置和来源
- **数据血缘分析**：追踪字段从产生到消费的完整链路
