## 常见数据问题与排障

### 问题1：数据缺失

**现象**：
- {field1} 存在，但关联的 {field3} 为空

**可能原因**：
1. {环节2}/{子环节B} 处理失败，未写入 {field3}
2. {环节2} 与 {环节1} 之间的消息丢失

**排查路径**：
1. 在元数据中定位与本实体/创建链相关的 **identifier**（见上文「黄金/非黄金」），核对查询侧是否正常
2. 检查 {环节2}/{子环节B} 的日志
3. 查询消息队列积压情况

**关联文档**：
- `02-领域认知/{环节2}/{子环节B}.md` 中的【故障模式】

### 问题2：数据不一致

**现象**：
- {field3} 显示为 {状态A}，但实际业务已处于 {状态B}

**可能原因**：
1. 状态机推进异常
2. 并发更新导致的状态覆盖

**排查路径**：
1. 检查 {field6}（更新时间）与业务实际变更时间是否匹配
2. 检查 {环节2} 的并发控制逻辑
3. 查看 `02-领域认知/{环节2}/整体逻辑.md` 中的状态机定义
