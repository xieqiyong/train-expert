# 05-自我进化经验库索引

## 概述

**自我进化层**用于记录 skill 在实际使用过程中积累的经验教训、成功路径和常见陷阱，形成持续改进的闭环。

### 设计原则
- **运行时积累**：经验来自实际使用，非设计阶段编写
- **可追溯性**：每个经验都与具体环节/指标/场景关联
- **可操作性**：经验需提炼为可执行的判断规则或步骤

## 读取策略指南

### 何时读取经验教训

**必读场景**：
- 架构认知时 → 读取相关环节的架构误解案例
- 故障排查步骤3-5时 → 读取该环节的误判案例
- 故障排查结论推演时 → 对比已纠正案例

**选读场景**：
- 遇到复杂问题时 → 搜索类似场景的经验
- 处理异常指标时 → 读取该指标的误判历史

### 何时读取成功路径

**必读场景**：
- 智能问数时 → 读取类似查询的最优路径
- 巡检开始时 → 读取高效巡检路径
- 故障排查前 → 读取类似问题的快速定位路径

**选读场景**：
- 响应较慢时 → 检查是否有更优路径
- 流程优化时 → 参考已验证的高效方式

### 何时读取常见陷阱

**必读场景**：
- 故障排查进入某环节详细分析时 → 检查该环节陷阱
- 准备下结论时 → 对照陷阱自查清单
- 处理指标异常时 → 检查指标相关陷阱

**选读场景**：
- 新接触某环节时 → 了解易错点
- 培训新人时 → 重点强调常见陷阱

## 新增经验的规范

### 新增经验教训

当发生以下情况时，应新增经验教训：
1. 初始判断错误，后续纠正了
2. 踩了未记录的陷阱
3. 发现文档与实际情况不符

**文件命名**：`经验教训/{YYYYMMDD}-{环节}-{问题简述}.md`

**必须包含**：
- 问题现象（原始问题描述）
- 初始判断（错误的思路）
- 实际根因（真相）
- 纠正过程（如何发现和修正）
- 经验提炼（可复用的判断规则）
- 关联文档（相关环节/实体/指标）

### 新增成功路径

当发生以下情况时，应新增成功路径：
1. 找到比现有路径更快的方式
2. 成功解决了一个复杂问题
3. 验证了某种高效的处理模式

**文件命名**：`成功路径/{问题类型}-{场景}.md`

**必须包含**：
- 触发条件（什么情况下使用）
- 最优路径（详细步骤）
- 效率分析（为什么这样快）
- 验证结果（成功案例）

### 新增常见陷阱

当发现以下情况时，应新增陷阱：
1. 某类错误反复出现
2. 文档有误导性表述
3. 某个指标容易被误解

**文件命名**：`常见陷阱/{环节}-{陷阱类型}.md`

**必须包含**：
- 陷阱描述（什么情况下容易犯错）
- 典型症状（如何识别）
- 规避方法（预防措施）
- 自查清单（执行前检查）

## 版本间经验继承

当新版本发布时：

1. **自动继承**：将上一版本的 05-自我进化/ 复制到新版本
2. **标记来源**：在经验文件头部添加 `来源版本: {version}`
3. **验证更新**：根据新版本架构变化，验证经验是否仍适用
4. **标记失效**：如经验不再适用，移动到 `经验教训/失效/` 目录
